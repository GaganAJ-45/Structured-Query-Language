## **Structured Query Language**
- SQL is a standard Programming language used to communicate and manage data in relational database M systems such as MySQL, PostgreSQL, Oracle SQL, and Microsoft SQL Server.
- SQL is used for :
   - creating databases and tables
  - inserting data into tables
  - deleting tables
  - dropping tables
  - updating data
  - managing users and permissions
 
 
### **Why SQL Is Used**
1. It is easy to learn
2. the standard language for databases
3. It handles large volumes of data
4. supports data security
5. and is used in data analytics, business intelligence, web development, and software applications.


## **Categories of SQL commands**
#### 1.Data Definition Language(DDL)
- It defines the database structure.
**Commands**
1. Create
2. Drop
3. Alter
4. Truncate
5. rename

*Examples*
```sql
Create Database Agriculture;

Create Table Farming(
Ph_Name serial Primary key,
Number Int unique,
Email varchar(20) Not null);
```
